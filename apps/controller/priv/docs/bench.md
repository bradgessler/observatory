# Bench

Every control surface side by side under one header: the scope's live
state, the game pad, the camera, one always-visible STOP, and a chip for
any mode that changes where the scope goes.

## Why it exists

The bench is where new ways of driving the mount get tried next to each
other in the same evening — strips, keypad, nudge, orb, tilt, position, pad.
Anyone can open it and play; the header keeps the picture of what the
telescope is actually doing whichever surface is up. It is not the field UI;
the front door lists each thing on its own.
