# Centering in the eyepiece

The Center page moves what you see, not the axes. Each arrow moves the view that way by one step: tap Down and the object moves down in the eyepiece. The steps are in arcminutes, with the share of your eyepiece's field beside them.

## Which way is which

Which axis moves the view which way depends on three things: the side of the pier the tube is on, whether there is a star diagonal (it mirrors one direction), and how the eyepiece is turned. For one setup it stays the same all night, so it is a setting, not a guess. The first time a tap goes the wrong way, tap **Up/Down Backwards** or **Left/Right Backwards** once; every page and phone gets the change. A meridian flip turns the view 180°.

Under each arrow is the axis it drives (RA or Dec) and the direction, so the mapping is never hidden.

## Centered

When the object sits on the crosshair, tap **Centered**. It records the time and where both axes were, which is an [alignment point](/docs/glossary#alignment-point) for whatever is being tracked. The game controller's D-pad uses the same map of which way is which.

If up/down moves the view sideways instead, the eyepiece or star diagonal has been turned in its holder: tap **Up/Down and Left/Right Swapped** once, then fix any direction that is still reversed with its Backwards button.
